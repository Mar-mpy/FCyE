# Aprendemos Juntos — Formación Cívica y Ética 3.º

Sitio web educativo hecho con React + Vite, inspirado en un estilo editorial infantil y Material Design: superficies suaves, tarjetas, sombras, botones, navegación responsive y tipografía amigable.

## Contenido

- Inicio
- Temas: 3 bloques y 12 secuencias basadas en el libro de Formación Cívica y Ética de 3.º de primaria.
- Detalle de cada tema con resumen, referencia de página y preguntas para conversar en familia.
- Cuentos: página preparada para una siguiente etapa.
- Juegos: página preparada para una siguiente etapa.
- Navbar y menú móvil responsive.
